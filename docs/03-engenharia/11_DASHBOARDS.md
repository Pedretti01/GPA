# Dashboards Pedagógicos

**Ferramenta Multiplataforma de Apoio à Alfabetização**  
**Versão:** 0.2.0

---

# 1. Introdução

Os Dashboards constituem a principal interface analítica da ferramenta.

Seu objetivo é apresentar, de forma visual e organizada, os indicadores produzidos durante as atividades, permitindo que professores acompanhem a evolução dos estudantes e identifiquem necessidades de intervenção pedagógica.

Dashboards não substituem os relatórios. Eles complementam os relatórios oferecendo uma visão dinâmica da aprendizagem.

---

# 2. Objetivos

Os Dashboards possuem os seguintes objetivos:

- acompanhar o desempenho dos estudantes;
- acompanhar a evolução das turmas;
- identificar padrões de aprendizagem;
- identificar dificuldades recorrentes;
- facilitar a tomada de decisão pedagógica.

---

# 3. Tipos de Dashboard

## 3.1 Dashboard do Professor

Apresenta informações gerais das turmas sob responsabilidade do professor.

## 3.2 Dashboard da Turma

Apresenta indicadores consolidados de uma turma.

## 3.3 Dashboard do Estudante

Apresenta informações individuais.

## 3.4 Dashboard Administrativo

Reservado para versões futuras.

---

# 4. Perguntas Pedagógicas

Todo Dashboard deverá responder perguntas relevantes, como:

- Como está minha turma?
- Quem precisa de ajuda?
- Quais conteúdos precisam ser retomados?
- Como este estudante evoluiu?
- Como foi esta atividade?

---

# 5. Filtros

Os Dashboards deverão permitir filtros por:

- período;
- turma;
- estudante;
- categoria;
- complexidade linguística;
- mecânica;
- modalidade.

---

# 6. Relação com Relatórios

Relatório:

- registro formal;
- documentação;
- possível exportação.

Dashboard:

- acompanhamento contínuo;
- análise visual;
- exploração interativa.

---

# 7. Limites

Os Dashboards não realizarão diagnósticos automáticos.

As informações apresentadas representam evidências produzidas pela ferramenta e devem ser interpretadas pelo professor.

---

# 8. Considerações Finais

Os Dashboards transformam indicadores em informações visuais que auxiliam o professor na compreensão do processo de aprendizagem.
